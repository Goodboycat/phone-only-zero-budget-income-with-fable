# Prompt 1 - Local business website

```
Build a one-page website for a [TYPE OF BUSINESS, e.g. barber shop] called "[BUSINESS NAME]" in [CITY, COUNTRY].

Sections, in this order:
1. Header with business name and a one-line promise.
2. Big "Chat on WhatsApp" button that opens https://wa.me/[PHONE WITH COUNTRY CODE, NO +] with a pre-filled greeting.
3. Services with prices in [CURRENCY].
4. Photo gallery (6 placeholders).
5. Opening hours.
6. Location with a "Open in Google Maps" link.
7. Three short customer reviews (mark them clearly as SAMPLE so I replace them with real ones).
8. Footer with phone number and "Website by [MY NAME]".

Style: [e.g. clean, dark with gold accents]. Language: [LANGUAGE].

Technical rules:
- Give me ONE complete file named index.html with all CSS and JavaScript inside it.
- No external libraries, fonts, frameworks or build steps. It must work offline after loading.
- Design for a small Android screen first (360px wide). Large tap targets, readable text.
- Keep it light for slow mobile data: no large images; use placeholders I can replace with my own photo links.
- I will host it on GitHub Pages using only my phone browser, so nothing may need a server.
- Put all text I need to change (names, prices, phone number) in one clearly marked block at the top of the script.
- After the code, list in plain words exactly what I must edit.
```

## Follow-up prompts

- "Make a second version with a completely different colour style for a [OTHER BUSINESS TYPE]."
- "Replace all sample details with these real ones: [PASTE DETAILS FROM CLIENT]."
- "Add a simple price list table I can print."

Never leave sample reviews on a real client site. Use real ones or remove the section.
