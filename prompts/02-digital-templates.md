# Prompt 2 - Digital template bundle

```
I want to sell a bundle of printable templates for [AUDIENCE, e.g. final-year students applying for their first job] in [COUNTRY].

First, list 10 template ideas this audience would pay a small amount for, and mark the 5 most useful. Wait for my choice.

Then, for each chosen template, build a separate complete HTML file that:
- Is sized for A4 printing and looks correct when I use Chrome on Android > Share > Print > Save as PDF.
- Has fields I can type into before printing, and also prints well when left empty.
- Uses only black, white and one accent colour so it prints cheaply.
- Contains original wording and layout only. Do not copy any existing brand or template.

Technical rules:
- Give me ONE complete file named index.html with all CSS and JavaScript inside it.
- No external libraries, fonts, frameworks or build steps. It must work offline after loading.
- Design for a small Android screen first (360px wide). Large tap targets, readable text.
- Keep it light for slow mobile data: no large images; use placeholders I can replace with my own photo links.
- I will host it on GitHub Pages using only my phone browser, so nothing may need a server.
- Put all text I need to change (names, prices, phone number) in one clearly marked block at the top of the script.
- After the code, list in plain words exactly what I must edit.
```

## Then ask for the sales page text

```
Write the product listing for this bundle: a title under 60 characters, a 2-sentence summary, 5 bullet points of what is inside, who it is for, who it is NOT for, and 5 FAQ answers. Plain honest language, no exaggerated claims, no fake scarcity.
```
