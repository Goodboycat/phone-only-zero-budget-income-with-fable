# 1. Phone setup (free, about 30 minutes)

Everything is done in **Chrome on Android**. No PC, no paid app.

## Accounts to create (all free)

| Account | Why | Notes |
|---|---|---|
| Gmail | Login for everything else | Use one address for all business accounts |
| GitHub | Stores your files and hosts websites free (GitHub Pages) | Works fully in the mobile browser |
| Gumroad, Ko-fi or a local store (e.g. Selar in Africa) | Sell digital files | No monthly fee on the basic plan; they take a cut per sale. Check which one pays out to your country |
| Itch.io | Sell or share browser games/tools | Optional |
| WhatsApp Business | Talk to local clients, show a catalogue | Free app |
| Canva (free plan) | Covers, thumbnails, simple graphics | Optional |

## Phone tips for a low-RAM device

- Close other apps before working; keep only Chrome open.
- In Chrome use **Menu > Desktop site** only when a page refuses to work on mobile; switch it back afterwards.
- Keep files small: one `index.html` per product. No frameworks, no build step.
- Work offline when you can: write text in a notes app, paste later, to save data.
- Back up everything to GitHub so a lost or broken phone does not lose your work.

## How to publish a website from the phone (GitHub Pages)

1. Open github.com in Chrome and sign in.
2. Tap **+ > New repository**. Name it, choose **Public**, tick **Add a README**, create.
3. Tap **Add file > Create new file**. Name it `index.html`.
4. Paste the code Fable gave you. Tap **Commit changes**.
5. Go to **Settings > Pages**. Under *Branch* choose `main` and `/ (root)`. Save.
6. After 1-2 minutes your site is live at `https://YOURNAME.github.io/REPONAME/`.
7. To change it later: open the file, tap the pencil icon, edit, commit.

## How to test before publishing

- Ask Fable to give you **one complete HTML file**.
- Publish it, then open the link in Chrome and in a private tab.
- Send the link to a friend with a different phone and ask what is confusing.

## Security basics

- Turn on two-factor login for Gmail and GitHub.
- Never paste passwords or access tokens into a public file, chat group or screenshot.
- Never pay a "registration fee" to start earning. Real platforms do not charge one.
