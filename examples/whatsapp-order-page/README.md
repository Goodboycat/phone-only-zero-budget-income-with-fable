# Example: WhatsApp order page

A menu page where customers pick items and the order opens in WhatsApp already typed. One file, no server, no libraries.

## Use it for a client

1. Copy `index.html` into a new GitHub repository (see `docs/01-phone-setup.md`).
2. Edit only the block marked **EDIT THIS BLOCK ONLY**: shop name, note, WhatsApp number (country code + number, no `+`), currency, menu.
3. Turn on GitHub Pages and send the link to the shop owner.
4. Place a test order to your own number before handing it over.

The sample shop, phone number and prices are placeholders.
