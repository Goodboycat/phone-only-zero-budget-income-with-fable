# Prompt 3 - Micro web tool

```
Build a small free web tool: [WHAT IT DOES, e.g. a GPA calculator for the grading system used in COUNTRY / a unit-price comparer for market shopping / a savings goal calculator].

Requirements:
- The person gets a useful result within 10 seconds of opening the page.
- Show the working, not only the answer, so people trust it.
- Remember the last inputs on the device using localStorage.
- A "Share result" button that uses the phone's share menu when available, otherwise copies text.
- At the bottom: a short "Made by [MY NAME]" line with a link to [MY PORTFOLIO OR PRODUCT LINK].
- Check the maths with three worked examples and show me those examples after the code.

Technical rules:
- Give me ONE complete file named index.html with all CSS and JavaScript inside it.
- No external libraries, fonts, frameworks or build steps. It must work offline after loading.
- Design for a small Android screen first (360px wide). Large tap targets, readable text.
- Keep it light for slow mobile data: no large images; use placeholders I can replace with my own photo links.
- I will host it on GitHub Pages using only my phone browser, so nothing may need a server.
- Put all text I need to change (names, prices, phone number) in one clearly marked block at the top of the script.
- After the code, list in plain words exactly what I must edit.
```

Test the three worked examples yourself with a phone calculator before publishing. A calculator that is wrong damages your name.
