# Prompt 6 - Fixing and improving

## When something is broken

```
This is my current index.html: [PASTE THE WHOLE FILE]

Problem: when I [WHAT I TAPPED OR TYPED], I expected [WHAT SHOULD HAPPEN] but instead [WHAT HAPPENED]. Phone: Android, Chrome.

Find the cause, explain it in one sentence, and give me the whole corrected file.
```

## When you want a change

```
This is my current index.html: [PASTE THE WHOLE FILE]

Change only this: [THE CHANGE]. Keep everything else exactly the same. Give me the whole file again.
```

## Quality check before delivering to a client

```
Review this page as a strict tester for a small Android screen on slow data: [PASTE FILE]. List problems in order of seriousness: broken buttons, text too small, anything that needs internet after loading, spelling mistakes, missing details a customer would look for. Then give me the corrected file.
```
